# The door

The documents in this repository that carry authority. If a document is not on this
list it has no authority here, whatever its own body says about itself. Nothing gets
on by claiming to belong; a person puts it here.

Admission is one test with two ways to pass. A document is **law**, meaning an
append-only ledger where the highest entry on a topic wins, or it is **re-measurable**,
meaning it prints a command that proves its own claims. Anything else is a snapshot.
Snapshots are useful and legitimate and they do not go on this list.

Run `python3 check_door.py` to see whether everything below still passes.

## D-1 2026-08-21 - Admitted

- [`ledger-template.md`](ledger-template.md) - law. The shape an append-only ledger takes.
- [`re-measurable-template.md`](re-measurable-template.md) - re-measurable. A document that proves its own claims.

## D-2 2026-08-21 - Deliberately NOT admitted

`README.md` explains what this repository is. `essay.md` is an argument. `agent-prompt.md`
is an instruction to hand an assistant. All three are useful and none of them may stop you,
so none of them is on the door. Keeping them off is the demonstration.
